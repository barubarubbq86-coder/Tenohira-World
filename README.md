# てのひらの世界 — GitHub Pages v32

スマホ・タブレット用の静的Webゲームです。Pythonやビルド作業は不要です。

## 公開・更新

1. ZIPを解凍し、`index.html`、`assets/`など中身をリポジトリの直下へすべてアップロードします。古い同名ファイルは上書きしてください。ZIPだけをGitHubに置いてもゲームは更新されません。
2. GitHub Settings → Pages で `Deploy from a branch`、`main` と `/(root)` を選びます。既に設定済みなら更新後の反映を待ちます。
3. GitHub PagesのURLをChromeで開き、画面に `32` と表示されることを確認します。ホーム画面の旧アプリは通信をオンにして開き直します。旧版が残る場合は、ゲーム内の「保存」で世界のJSONを確保してから、そのサイトのデータを削除してください。

保存ファイルはJSON形式です。別端末への移行やサイトデータ削除後はゲーム内の「読込」から復元できます。

## 新機能

人・動物を選択して「操る」。地図をタップして移動や資源への行動、所属国からの侵攻を指示します。怪獣はビッグマンモスとドジラ。災厄メニューのビッグバンクハツは範囲確認後の2回目のタップで発動します。
