# てのひらの世界 — GitHub Pages 版

スマホ・タブレットのブラウザで遊べる静的 Web ゲームです。Python やビルド作業は不要です。

## 公開方法

1. ZIP を解凍します。GitHub の新しいリポジトリに、`index.html` と `assets/` など解凍した中身をリポジトリの直下へアップロードします。ZIP ファイルだけをアップロードしてもゲームは開けません。
2. GitHub の **Settings → Pages** で **Deploy from a branch** を選び、`main` ブランチの `/(root)` を選んで保存します。
3. Pages に表示された URL をスマホで開きます。インストールはゲーム内の「アプリをインストール」またはブラウザのホーム画面追加を使えます。

ゲームの「保存」は JSON ファイルとしてダウンロードします。端末を替えるときは「読込」で復元してください。ページの公開は、アクセスした誰もがゲームを遊べる状態にします。
