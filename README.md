# てのひらの世界 · 試作20

スマホ・タブレット向けのオリジナル世界シミュレーションです。インターネット通信やログインは使用しません。保存は端末にJSONファイルをダウンロードします。

## GitHub Pages で公開する

1. このZIPを展開します。ZIPそのものをGitHubへアップしてもサイトにはなりません。
2. 新しい公開リポジトリ、または既存リポジトリのルートに、展開した**中身全部**（`index.html`、各 `.js`、`assets/` など）を同じ配置でアップロードします。
3. リポジトリの **Settings → Pages** で **Deploy from a branch**、`main`、`/(root)` を選びます。
4. 表示されたHTTPSのURLをAndroidのChromeで開きます。Chromeメニューから「ホーム画面に追加」を選ぶとアプリのように起動できます。

同じリポジトリを更新する場合も、展開した中身を上書きしてください。古いキャッシュが残るときはページを再読み込みしてください。
