# てのひらの世界 · 試作22

Androidスマホ・タブレット向けのオリジナル世界シミュレーションです。

## GitHub Pages の更新

1. ZIPを展開して、中にある `index.html`、JavaScript、`assets/`、アイコン、マニフェスト、`sw.js` を含む**全ファイル**を公開リポジトリのルートに上書きアップロードします。ZIPそのものをアップしても公開されません。
2. GitHubの Settings → Pages で `main` ブランチの `/(root)` を公開します。設定済みなら変更不要です。
3. 公開URLをHTTPSで開き、「LITTLE WORLD · 22」と表示されることを確認してください。古い場合はページを更新し、閉じて開き直してください。

## Androidでアプリとして使う

Chromeで公開URLを開き、「アプリをインストール」を押します。端末に直接確認画面が出ない場合は右上の「︙」→「アプリをインストール」または「ホーム画面に追加」を選びます。インストール後はホーム画面のアイコンから起動できます。iPhone/iPadの場合はSafariの共有→「ホーム画面に追加」です。`file://`で開いた場合はインストールできません。

## 今回の変更

新規作成する地図は240×160マス（旧480×320マスの1/4の面積）。旧480×320マスのセーブは大きさを維持して読めます。小さい地図にする場合は、新しい世界を作成します。必要ならその前に保存してください。
食料・木・石を増やし、集落の成立前に資源が不足するケースを減らしました。家5軒で集落、同一集落10軒または近い集落2つと人口16人で国の目安です。まず大人20～40人程度を近い草原へ置くと変化を確かめやすいです。
地図の初期描画も一括生成に変更しました。アプリ化は起動しやすさとオフライン利用に役立ちますが、端末そのものの処理性能は上げません。

保存データは「保存」でJSONファイルとして端末へダウンロードできます。
