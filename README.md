# てのひらの世界 · 試作21

Androidスマホ・タブレット向けのオリジナル世界シミュレーションです。

## GitHub Pages への更新

1. ZIPを展開し、`index.html`、`.js`、`assets/` など**展開した中身全部**を、公開リポジトリのルートに上書きアップロードします。ZIP自体をアップしてもゲームは公開されません。
2. Settings → Pages で `main` ブランチの `/(root)` を公開します。既に設定済みなら変更不要です。
3. HTTPSのゲームURLを開き、画面上部が「LITTLE WORLD · 21」になっていることを確認します。古い場合はアプリを閉じて開き直すか、ページを再読み込みします。

## スマホでの確認

- 速度を10倍にすると、世界時間の1か月は約6秒で進む設計です。時計には日付も表示します。
- 早送りボタンの「実際 ○倍」は約3秒ごとに更新します。設定が10倍でも実際の値が低いときは、端末が計算に追いついていません。
- 音楽は最初の画面操作後に再生します。「再生できません」と出たときは音楽ボタンをタップして再試行できます。端末のメディア音量も確認してください。
- 「世界in石」ボタンを押して地図をタップすると、隕石が飛来します。

保存データは端末へJSONでダウンロードします。`file://`で直接開くとPWAのオフライン機能は働きません。HTTPSのGitHub Pagesから開いてください。
