てのひらの世界 08.1 — GitHub公開用

【最初に】
このZIPには公開に必要な完成ファイルが入っています。コードの編集、Python、ビルド作業、APIキーは不要です。
ZIPを解凍して「中身のファイル全部」をアップロードしてください。ZIPそのものや、親フォルダーだけをアップロードしないでください。
index.html がリポジトリの最上位にある形にします。

【新しく公開する場合】
1. 保護者のGitHubアカウントで新しいリポジトリを作ります。
   例：tenohira-world。GitHub Freeで公開する場合はPublicを選びます。
2. リポジトリで Add file → Upload files（新規作成直後は uploading an existing file）を開きます。
3. 解凍したファイルを全部アップロードし、Commit changesで確定します。
4. Settings → Pages を開きます。
5. Sourceは「Deploy from a branch」、Branchは「main」、フォルダーは「/(root)」にしてSaveを押します。
   main以外のブランチを使っている場合は、実際にアップロードしたブランチを選びます。
6. 公開が完了するとPages画面にURLが表示されます。そのURLをAndroidのChromeで開きます。
   公開URLを遊ぶ人に共有します。閲覧者にGitHubやChatGPTへのログインを求める処理はありません。

公開元の設定はZIPの中から自動で変更できません。初回の手順4〜5だけは必要です。
すでにPagesをmainと/(root)で公開済みなら、同名ファイルを更新してCommitするだけです。
同じリポジトリに別のゲームがある場合は、そのゲームを上書きせず、このゲーム専用のリポジトリを作ってください。

【遊び方】
・陸地を描く：太さを選んで海をなぞります。2本指で地図の移動・拡大縮小。
・人を置く：性別と年齢を選び、砂浜・草原をタップ。
・見わたす：人をタップして状態確認。重なった人は繰り返しタップで切り替え。
・保存：端末にJSONファイルをダウンロード。読込：保存ファイルを選択し、確認後に再開。
・自動保存ではありません。遊び終わる前に保存してください。
・試作07・08の保存データを読み込めます。
・スマホとタブレットは自動同期しません。保存ファイルを移して続きを遊びます。

【確認すること】
・画面下に「試作08.1」が表示されること。
・人を配置できること。保存→読込→再開ができること。
・以前の版が残る場合は、いったんゲームのタブを閉じて開き直してください。
・HTMLを端末上で直接開く方法は対象外です。公開URLから遊んでください。
